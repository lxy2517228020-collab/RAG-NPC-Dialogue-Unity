# Resume Project Summary

## Chinese resume version

- 开发 Unity 编辑器 NPC 对话生成插件，支持 NPC Profile 持久化、Gemini API 生成、DialogueSet ScriptableObject 保存与运行时 NPC 对话展示。
- 实现本地 Lore 文档加载、文本切块、Keyword RAG 与 Gemini Embedding + Cosine Similarity 的 Semantic RAG 检索流程。
- 构建 No-RAG / Keyword-RAG / Semantic-RAG 对比演示，用 Roland 夜间帮助反抗组织的剧情验证语义检索对游戏世界观 grounding 的作用。

## English resume version

- Built a Unity Editor NPC dialogue generation plugin with persistent NPC profiles, Gemini API generation, DialogueSet ScriptableObject saving, and runtime NPC dialogue display.
- Implemented local lore loading, text chunking, Keyword RAG, and Semantic RAG using Gemini embeddings with cosine similarity.
- Created a No-RAG / Keyword-RAG / Semantic-RAG comparison demo showing how semantic retrieval grounds NPC dialogue in game lore.
